# 🌱 AgriScan-AI

### Crop Disease Detection Using CNN

AgriScan-AI is a crop disease detection project that uses Convolutional Neural Networks (CNN) to help identify plant diseases from crop images.

## 📥 Download the Project Dataset

**Download the complete crop dataset ZIP file here:**

[⬇️ Download crop.zip](https://github.com/CHNIKHIL-2005/AgriScan-AI/raw/main/crop.zip)

Click the link above to download the ZIP file directly to your computer.

## 🚀 Getting Started

1. Download `crop.zip` using the link above.
2. Extract the ZIP file to your preferred folder.
3. Follow the project setup instructions to run the application.

## 📂 Repository Contents

- `crop.zip` — Crop dataset archive.
- `README.md` — Project documentation.
- `.gitattributes` — Git Large File Storage (LFS) configuration.

## 🛠️ Technologies Used

- Python
- Convolutional Neural Networks (CNN)
